Политика конфиденциальности приложения «rclone backup»

Приложение «rclone backup» — внутренний инструмент ООО «Фабрика роста» для резервного копирования файлов компании с Яндекс Диска на Google Drive, принадлежащий компании. Приложение не предназначено для сторонних пользователей.

Приложение получает доступ к Google Drive только того аккаунта, владелец которого сам дал разрешение, и использует этот доступ исключительно для создания и обновления резервных копий файлов компании.

Данные не передаются третьим лицам, не продаются и не используются для рекламы или аналитики. Файлы хранятся только в Google Drive владельца аккаунта и на сервере компании, через который выполняется копирование.

Использование информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Отозвать доступ можно в любой момент: https://myaccount.google.com/permissions
